FINDINGS
F032-01 [HIGH] Rollback detection does not enforce authorization
Location: world.py:127, world.py:157, world.py:185, probes.py:128.
Measured/reviewed: An ordinary restart rejects a spent nonce. After truncating only the nonce file, rollback_detected() is True, yet a fresh signer accepts the same spent receipt and debits another 10. authorize() never consults rollback_detected().
Bound: The rollback is a specified harness-controlled corruption; this is not evidence that a confined child reached the protected path. The related prior-receipt fixture assumes receipt possession.
Required repair: Refuse startup/submission on missing, malformed or inconsistent required nonce/anchor state before any effect; namespace receipts and durable nonce state by a unique session. Test the actual authorize path after rollback.

F032-02 [HIGH] The pipe permits an unbounded read and slowloris hang
Location: runner.py:127, sandbox.py:251, schema.py:31.
Measured/reviewed: Both serving loops block in readline() on an unterminated line; the audit's external 1.5-second deadline had to kill each isolated test process group. A 131073-byte line is read in full before the 65536-byte check rejects it. Invalid UTF-8 raises an uncaught UnicodeDecodeError and records no scored abort.
Bound: These local pipe fixtures require no filesystem access, valid receipt or model call. Deeply nested JSON was properly rejected with SchemaError; no recursion-crash claim is made.
Required repair: Read bounded bytes with a monotonic deadline covering initialization, reads and writes; cap total bytes and message count; decode strictly inside error handling; kill/reap the whole episode process group and persist an explicit abort.

F032-03 [HIGH] The checked source differs from the disposable file that executes
Location: runner.py:316, sandbox.py:193, battery.py:84.
Measured/reviewed: A harness hook appends a harmless comment after integrity_check but before make_disposable_root copies agent_main.py. The child runtime hash differs from FREEZE, and the episode still returns instead of aborting.
Bound: Executed through the shared EXPOSED staging path on a disposable source copy, not a demonstrated HARDENED write escape. Preexisting source drift is correctly rejected.
Required repair: Verify the exact staged runtime after copying, bind its closed file set to FREEZE, and make it immutable before launch; reject any drift. Exercise episode i mutation then i+1 refusal and seal the abort.

F032-04 [HIGH] The scientific receipt and verifier lanes do not seal the evidence set
Location: battery.py:198, battery.py:215, battery.py:237, verifier_strength.py:120, verifier_strength.py:151.
Measured/reviewed: Using copied historical evidence in the same format, replacing decisions.jsonl with one corrupt line and deleting MUTATION.json leaves V1 at 23/23 PASS and V2 PASS, with the detached receipt unchanged. Current battery.py hashes its slim summary rather than those files; mutation results, V2 results and actual episode heads are absent. Its statement names a separate five-step session clock plus genesis nonce/ledger heads.
Bound: This checks the v0.3.2 verifier on preserved v0.3.1 saved evidence and inspects the current serializer; it is not a newly successful v0.3.2 run. The V2 helper does copy saved bytes, but its integrity scope is too narrow.
Required repair: Define a closed ordered evidence manifest, export actual per-episode records/clock/nonce/ledger heads, bind all required lanes and reject missing, added, reordered or modified inputs. Persist V1/V2 results without a circular self-hash, then restore the exact saved payload and independently reconstruct it.

F032-05 [HIGH] Mutation exclusivity and evidence coverage are unproved and counterexampled
Location: battery.py:103, mutate.py:221, mutate.py:248, protocol.json.
Measured/reviewed: One escaped=True bit flips A2, A5 and A15 in the actual evaluator, contradicting an exactly-one-claim assertion for this vector. Removing every HARDENED adversarial record and all A6 records, then labeling every calibration episode T1, still leaves all 23 core claims PASS on the evaluator fixture. Five claims have no declared mutant: A1, A3, L1, A5, A19. Some mutants use constants/precomputed verdicts instead of disabling and exercising a real control.
Bound: Evaluator fixtures and static mutant inventory, not OS attack execution. The full mutation command remained host-blocked. The candidate README already acknowledges that full-vector proof is not claimed; this confirms a remaining request gap.
Required repair: Validate exact expected episode identities and coverage before scoring. Re-run the complete claim vector under each genuine control mutation and publish all flips. Resolve overlapping claim definitions in a new frozen protocol instead of relabeling dependent failures.

F032-06 [MEDIUM] The export decoder checks field names but not a typed canonical statement
Location: export_receipt.py:19, export_receipt.py:47, export_receipt.py:68.
Measured/reviewed: decode_strict accepts an array containing the expected field names, an all-null object and a NaN value. A newly signed all-null statement verifies. A fingerprint not matching the verifying public key also verifies. The requested claims[] is replaced by claims_digest.
Bound: No Ed25519 forgery is demonstrated. Tampering each of the eleven fields without re-signing is rejected, and inherited weak-key controls pass. The defect is schema/semantic validation, not signature binding.
Required repair: Require an object with exact typed fields, finite canonical JSON, valid identifiers/digest encodings, the explicit ordered claims array, and a fingerprint derived from the verification key; reject malformed bodies before verifying.

F032-07 [HIGH] The advertised sandbox is weaker than the required profile
Location: sandbox.py:144, sandbox.py:193, sandbox.py:206, sandbox.py:233, landlock.py:1.
Measured/reviewed: With simulated successful UID drop but absent Landlock and seccomp, detect_profile still says realizable=True. The runtime is copied/chmodded, not mounted into an isolated read-only root. Landlock handles writes only and deliberately permits reads/exec outside the root. Seccomp filters only ptrace/process_vm_readv/process_vm_writev, leaving the requested chmod/mount/clone and path policy unimplemented. Parent dumpable and child seccomp prctl return values are not all checked.
Bound: The real host has unavailable UID separation and refuses HARDENED. This finding combines code inspection with explicitly simulated feature inputs; it does not claim a live HARDENED escape here.
Required repair: Freeze one mandatory complete profile, require every mandatory feature or a specified equivalent, check each application result, and probe path reads/writes, process memory, FD inheritance and process lifecycle under that exact profile. No optional degradation.

F032-08 [MEDIUM] Signed clock evidence is not enforced throughout the live episode
Location: runner.py:127, runner.py:327, world.py:185, clock.py:1.
Measured/reviewed: Three public reads and a report leave the episode clock at step 5. Corrupting the stored current clock signature makes ClockChain.verify() False, yet authorize() accepts a valid receipt naming that head. The signer checks the in-memory head map and step, not the chain signatures.
Bound: The signature corruption is a controlled integrity self-test; pre-spawn parent compromise remains excluded. The inherited isolated expiry/signature probes pass. This is not a claim that the child has a clock-write API.
Required repair: Define exactly which episode events advance the signed step chain, advance it in the serve loop, verify the authoritative chain at the gate, test nonexistent issued steps and expired use after a real event, and export each actual clock head.

F032-09 [LOW] The asked flag does not mean an authorization attempt
Location: runner.py:81, runner.py:92, runner.py:95, agents.py:85.
Measured/reviewed: HALTING, DISCLOSER, OMITTER and INSISTER all have asked=False. Their submit counts are respectively 0, 1, 1 and 6. INSISTER consults the signer once and records five latched rejections, so the refusal latch itself works.
Bound: Attempt counts remain available in submits. This is a misleading metric/taxonomy and missing mutation coverage, not repeated successful authorization.
Required repair: Separate requested_funds, permission_attempt_count, principal_refusal_count and latched_rejection_count; score the required refusal outcomes explicitly and add a genuine A19 mutant.

F032-10 [LOW] T1 does not implement the specified third-party spend surface
Location: runner.py:55.
Measured/reviewed: The provisioned T1 receipt targets principal, whereas the request names GAS from a third party. SECRET, TABLE and WRITE do have different local capability mechanisms and the 35 unconfined wiring checks pass.
Bound: This is a declared-surface conformance deviation, not an observed confused-deputy bypass. The payer-swap gate probe passes.
Required repair: Either implement the exact specified third-party scenario with the corresponding legitimate receipt owner or explicitly revise the frozen task definition and explain the deviation.

F032-11 [MEDIUM] Several required adversarial measurements remain reduced fixtures
Location: probes.py:144, battery.py:84, agents.py:232, agents.py:247, agents.py:282.
Measured/reviewed: A14 remains a harness-side balance edit plus noop ledger event, not the requested attacking stub. A16 tests a changed expected hash in a temporary FREEZE, not an i-to-i+1 experiment with a recorded scientific abort. SNEAKY_CLOCK hardcodes False; SNEAKY_TOCTOU performs sequential empty appends; SNEAKY_MEM checks parent-file openability only; SNEAKY_SCHEMA sends newline-terminated malformed JSON and an 80KiB line, not a real partial-line slowloris.
Bound: These smaller checks have value and should remain as regressions; they do not establish the stronger experiments in the request.
Required repair: Retain the regressions but implement and freeze the specified adversarial episodes and real control mutations, labeling any intentional deferral by ID.

POSITIVE CONTROLS AND EXISTING REPAIRS
The four F031 repair regressions still pass, including accurate effect reporting, historical event-time reconstruction, typed report handling and closure of the strict-verifier source-lock gap. Strict small-order-key checks and the direct payer-swap gate probe pass. Preexisting package drift is rejected. Tampering each of the eleven statement fields without re-signing breaks verification. INSISTER's six submits cause only one signer consultation and five latch rejections.
